### We are Cairn.

Long before version control, before compilers, before language itself, travelers stacked stones.

A cairn is the oldest protocol: *I was here. The path is safe. Keep going.*

One stone means nothing. Two stones are an accident. Three stones are a message. A dozen stones are a promise, left by someone who walked the hard way first so that you don't have to.

---

**Cairn Software** is a small research studio that builds things at the boundary between intelligent systems and human craft. We stack stones in the fog.

Some of our cairns mark well-trodden trails:

- **🧠 [mneme](https://github.com/Cairn/mneme)**: *The Memory Layer.* Named for the Greek Titaness of memory and mother of the Muses, Mneme is a semantic caching library for LLM applications. She remembers what the models forget.

- **🌸 [floriography](https://github.com/Cairn/floriography)**: *A random flower, its Latin name, its Victorian meaning, and a verse from a real English poem.* In the 1800s, people sent entire love letters using nothing but flowers. We thought that was beautiful, so we built a machine that does the same thing.

- **🌐 [cairn.github.io](https://github.com/Cairn/cairn.github.io)**: *The official website and entry portal for Cairn Software.* Procedural double-helix backgrounds, animated pipeline showcases, and a project catalog, all compiled from TypeScript and served as static files, because some stones are best left simple.

Others mark paths we're still exploring, private trails through the fog. An autonomous coding agent written in Rust. An AI-native CRM that was, for a brief and terrifying chapter, built entirely by a free language model running through Discord. A security daemon that watches Linux filesystems with the quiet vigilance of a cathedral gargoyle. A museum of bizarre historical events rendered as oil paintings. An app that locks your phone until you finish your tasks. Vinyl stickers, because every expedition needs patches.

---

We believe software should be built like cairns: small, deliberate, and placed where someone will actually need them. No mass production. No growth hacking. Just stones, stacked carefully, one on top of another.

*The path is safe. Keep going.*
